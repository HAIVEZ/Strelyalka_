# Strelyalka
Strelyalka — 3D-платформер с элементами шутера, сделанный на GDevelop. *Особенность: если вы строите мост, не надейтесь на то, что он нормально встанет. Он стопроцентно полетит. Тогда можно просто перепрыгнуть. Как? Думайте.* 
Управление: WASD — движение, ←→ – поворот, ЛКМ – стрельба, ↑ – ускорение.
